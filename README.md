# Демо CRM

Живая демо-версия CRM: воронки продаж, лиды от физлиц, imBox, товары, почта
и отчёты по рекламным кампаниям, три города (Минск, Караганда, Алматы) со своими
менеджерами и номерами WhatsApp, роли доступа как в EspoCRM. Внизу страницы
переключатель «Смотреть как»: владелец видит всё, менеджер — свой город, стажёр —
только свои заявки, руководитель — все города без права правки. Права ролей
владелец меняет в «Настройках → Роли и доступ». Работает целиком в браузере
на демо-данных: изменения сохраняются до перезагрузки страницы.

Открыть: https://ainalineast-coder.github.io/crm-demo/
